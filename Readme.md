# 🎮 Esports Team Management Portal

A web-based Esports Team Management System built using ASP.NET Core MVC, Entity Framework Core (Database First), and SQL Server. The application helps manage Teams, Players, Coaches, Tournaments, and Matches while providing reporting features such as Leaderboards and Top Teams.

---
## 📌 Project Overview

The Esports Team Management Portal is designed to streamline esports organization management by providing:

- Team Management
- Player Management
- Coach Management
- Tournament Management
- Match Scheduling & Tracking
- Dashboard Analytics
- Leaderboard Reporting
- Top Teams Reporting
- User Authentication
